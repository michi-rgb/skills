# ミスミ カテゴリマップ（参考情報）

**注意：** このファイルは2026年7月時点でのWeb検索により確認できた情報をもとに
まとめたものです。ミスミのサイト構成・カテゴリ名・階層は随時変更されるため、
**完全性・最新性は保証されません**。ここに載っていないカテゴリも多数存在します。
詳細な階層や最新のカテゴリ名が必要な場合は、必ず web_search /
web_fetch で jp.misumi-ec.com の該当ページを直接確認してください。

## 大分類（事業カテゴリ）

### 1. FA用メカニカル標準部品（FA＝Factory Automation：工場自動化）
装置・設備を組み立てるための機械要素部品全般。確認できた中分類の例：

- フレーム・サポート部品・支柱／アルミフレーム・アクセサリ
- ベアリング
- カムフォロア
- カップリング・モータ
- タイミングプーリ／タイミングベルト
- 歯車
- ねじ・ボルト・座金・ナット
- 配線部品
- 制御・受配電・通信・電源／電設資材
- 産業用PC・PC部品・周辺機器（PC本体、ディスプレイ、キーボード・マウス、
  拡張ボード、KVM・ディスプレイエクステンダ、USBメモリ・SDカード、
  外付けドライブ・ストレージ、ディスプレイアームなど）
- ボックス・ボックス周辺部品（スチール・ステンレスボックス、アルミ・プラボックス、
  盤用パーツ・パネル、ファン、盤用クーラー、表示用部品、分電盤、ラックなど）
- タンク（攪拌機付加圧タンク、開放タンクなど）
- 配管部品（エア・油圧配管、サニタリー・真空配管など）
- 光電センサ
- 静電気対策部品
- 取手・ノブ

### 2. FA用エレクトロニクス部品
センサ・コネクタ・ハーネス・ケーブル・配線部品など、電気・電子系のFA部品。
ドライバ／ソフトウェア／取扱説明書のダウンロードページや、追加工・カスタム
サービス（ハーネスの結線指定など）も用意されている。

### 3. プレス金型部品
- パンチ＆ダイ
- ガイド部品
- 小物／周辺部品
- 圧力源

### 4. プラ型用部品（プラスチック射出成形金型の部品）
- エジェクタピン
- スリーブ／センターピン
- コアピン
- スプルー／ゲート／ランナー関連
- デートマーク／ガス抜き関連
- アンダーカット／プレート
- ガイド／位置決め／エジェクタスペース関連
- 型開き制御
- コイルスプリング／ノックピン／その他小物部品
- 大型／ダイカスト用部品
- 冷却／温調関連部品

### 5. 射出成形用部品
- 射出成形機・パーツ
- 射出成形金型パーツ
- 射出成形周辺機器・パーツ
- 成形ケミカル・現場ツール・保全

### 6. 切削工具
エンドミル・ドリル・バイトなど（詳細な中分類は未確認。必要に応じて公式サイトを検索）。

### 7. 研究・実験・開発用品（AXELブランドとして展開されることが多い）
- 樹脂製容器／ガラス製容器／金属製容器
- 粉砕・混合機器
- ガラス機器・ガラス器具
- 実験器具・小物
- 計量器具
- 超音波・洗浄機器
- 滅菌・消毒機器
- 顕微鏡用ガラス
- 蒸発・焼成用容器
- 分析・検査機器
- クリーンルーム用品
- 動植物実験用品

### 8. ハーネス・コネクタ・ケーブル・配線部品
FAメカニカル／エレクトロニクスの両方に関連する横断的なカテゴリとして
サイト上部メニューに表示されることがある。

## 補足サービス（カテゴリではないが、部品が見つからないときの選択肢）

- **カタログ規格外品サービス**：標準型番から追加工（サイズ変更など）を指定して
  見積もり・注文できるサービス（対象はFA／プレス／プラのミスミ品と案内されていた。
  対象範囲は変更される可能性があるため要確認）。
- **図面データからの見積もりサービス**：2D図面（PDF・DXF）をアップロードし、
  カタログに掲載されていないFAメカニカル部品を見積もり・注文できるサービス。

## 出典・確認方法についての注記

上記は以下のようなミスミ公式サイトのページ群から確認した内容です（2026年7月時点）。
- デジタルカタログ／総合Webカタログ（jp.misumi-ec.com/contents/catalog/misumi/ ほか）
- FAメカニカル標準部品の商品ラインナップ・特長ページ
- プレス金型・プラ型・射出成形用部品の特集ページ

いずれもクロールした断片的な情報のため、実際のメニュー構成・階層の深さ・名称は
サイト上で異なっている可能性があります。ユーザーへの回答時は、この参考情報を
「たたき台」としつつ、可能であれば実際にweb_searchでミスミのカテゴリページを
検索し、内容を確認・アップデートしてから案内してください。
