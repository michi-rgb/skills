# スライドプラン(JSON) スキーマ

`build_deck.js` / `make_pdf.py` が読むプランの完全な仕様。プランは1つのJSONオブジェクト。

## トップレベル

| キー | 型 | 説明 |
|---|---|---|
| `theme` | string | 現状 `"academic"` のみ（省略可、既定 academic）。 |
| `font` | string | 本文・見出しのフォント名（省略可、既定 `Noto Sans CJK JP`）。 |
| `fontHead` | string | 見出しだけ別フォントにしたいとき（省略可、既定は `font` と同じ）。 |
| `footer` | string | 全ページ下部に出す走り書き（文書タイトルの短縮など）。省略可。 |
| `slides` | array | スライド定義の配列（順序＝表示順）。**必須**。 |

**フォントの注意（重要）**：PDFはサンドボックス上の LibreOffice で描画される。指定した
フォントがそのサンドボックスに**インストールされていなければ自動代替**され、指定どおりには
ならない。`fc-list :lang=ja` で実在を確認すること。游ゴシック・メイリオ・ヒラギノなどの
商用/OS付属フォントは通常この環境に無いので、確実に反映したいなら実在する無償フォント
（`Noto Sans CJK JP` 等）を使う。どうしても特定フォントが要る場合は、その旨をユーザーに
伝えて選択肢（近い無償フォントで代替／編集可能な pptx も併せて渡し手元PCで書き出す）を示す。

図のパスは**プランJSONの位置からの相対パス**（または絶対パス）。フォルダごと
移動しても壊れないよう、図はプランと同じ階層の `images/` に置くとよい。

## スライド共通

各スライドは `type` を持つ。使える型: `title` / `agenda`(=`toc`) / `section` /
`content` / `summary`(=`closing`)。未知の型は `content` として扱う。

### `title`（表紙）
| キー | 説明 |
|---|---|
| `title` | 大見出し（文書タイトルの日本語訳）。 |
| `subtitle` | 一言サブタイトル。省略可。 |
| `meta` | 出典・日付など小さく出す情報。省略可。 |

### `agenda` / `toc`（目次）
| キー | 説明 |
|---|---|
| `title` | 見出し（既定「目次」）。 |
| `items` | 文字列配列。自動で 01, 02… と番号が付く。3〜6個推奨。 |

### `section`（節扉）
| キー | 説明 |
|---|---|
| `number` | 節番号（大きく表示）。省略可。 |
| `title` | 節タイトル。ネイビー背景の扉ページになる。 |

### `content`（内容スライド）
| キー | 説明 |
|---|---|
| `kicker` | 見出し上の小さなラベル（所属する節名など）。省略可。流れの手がかりになる。 |
| `title` | スライドの主張を1枚で言い切る見出し。 |
| `bullets` | 箇条書き配列（下記）。省略可。 |
| `figure` | 図1枚（下記）。省略可。 |
| `figures` | 図の配列（最大3枚を横並び）。`figure` と併用しない。 |
| `layout` | 省略可。`auto`(既定)/`text`/`text-figure`/`figure`/`figures`/`two-col`。 |

**bullet オブジェクト**
| キー | 説明 |
|---|---|
| `text` | 本文（必須）。1行、長くて2行に収める。 |
| `level` | 0=主要, 1=補足（インデント＋やや小さめ）。既定0。 |
| `head` | true でネイビーの小見出し風（グループの頭）。 |
| `bold` | true で太字強調。 |

文字列だけの配列でも可（`"text"` として扱う）。

**figure オブジェクト**
| キー | 説明 |
|---|---|
| `path` | 画像パス（プラン相対 or 絶対）。PNG/JPEG。 |
| `caption` | 図の下に出す日本語の補足1行（「図N: 〜」）。省略可だが付けるのが既定。 |

### `summary` / `closing`（まとめ）
| キー | 説明 |
|---|---|
| `title` | 見出し（既定「まとめ」）。 |
| `bullets` | 結論・含意を3〜5点。文字列配列でも bullet オブジェクトでも可。 |

## レイアウト自動判定（`content` で `layout` 省略時）

- 図2枚以上 → `figures`（横並び。bulletがあれば上に少しだけ置く）
- 図1枚 ＋ bullet あり → `text-figure`（左に要点、右に図）
- 図1枚 ＋ bullet なし → `figure`（図を大きく中央に）
- 図なし ＋ bullet 8個以上 → `two-col`（2段組）
- それ以外 → `text`（1段組）

意図した配置にならないときだけ `layout` を明示する。箇条書きのフォントサイズは
数と量から自動調整されるが、**それでも溢れるなら詰め込みすぎのサイン**。項目を
削るかスライドを分ける。

## 最小例

```json
{
  "theme": "academic",
  "footer": "繊維配向理論",
  "slides": [
    {"type":"title","title":"繊維強化樹脂の配向予測","subtitle":"流動計算に基づく理論の要点","meta":"出典: MPI_Theory.pdf"},
    {"type":"agenda","items":["背景","支配方程式","配向モデル","結論"]},
    {"type":"section","number":2,"title":"支配方程式"},
    {"type":"content","kicker":"支配方程式","title":"配向は流動場のせん断で決まる",
      "bullets":[
        {"text":"繊維は速度勾配に沿って回転する","level":0},
        {"text":"Jeffery方程式が基礎","level":1},
        {"text":"相互作用は拡散項で近似","level":0}
      ],
      "figure":{"path":"images/fig_p012_1.png","caption":"図3: せん断流中の繊維の回転"}},
    {"type":"summary","bullets":["配向は流動履歴に依存","予測には相互作用係数の校正が要る"]}
  ]
}
```
