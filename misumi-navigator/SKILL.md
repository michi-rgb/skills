# MISUMI カテゴリナビゲーター

ミスミ（MISUMI）は国内外3,000社以上のメーカー商品を扱う、FA
（Factory Automation：工場自動化）部品・金型部品・工具・工場消耗品・研究開発用品などの
専門商社／EC（Electronic Commerce：電子商取引）サイトです。取扱商品点数が非常に多く、
大分類・中分類・小分類が何段にも重なっているため、「どのカテゴリを見ればいいかわからない」
という相談が多く発生します。このスキルは、ユーザーの探し物からミスミの正しいカテゴリ
（またはそれに代わる検索方法）を推薦することが目的です。

## このスキルの前提（不確実性について）

- ミスミのカテゴリ構成・商品ラインナップ・価格は頻繁に更新されます。以下の
  `references/category-map.md` は2026年時点のWeb検索で確認できた大まかな構造の
  **参考情報**であり、最新かつ完全な一覧である保証はありません。
- 具体的な型番・価格・在庫・納期・カテゴリの正式名称など、確信が持てない情報は
  断定せず、必ず「最新情報はミスミの公式サイト（jp.misumi-ec.com）で確認してください」
  と案内すること。
- 迷ったら推測で埋めず、実際にミスミの公式サイトの情報で裏取りすること。ただし、
  直接のページ取得（web_fetchやcurl等）はBot対策によりほぼ失敗するため、具体的な
  手段は後述の「データ抽出手段」の章を参照。統合ブラウザ（Playwright等の画面操作型
  ツール）はなるべく使わず、web_searchなど軽量な手段を優先すること。

## ステップ1：探し物を明確にする

ミスミのカテゴリは「業界・用途」で大きく分かれているため、まずどの土俵に属するかを
特定する必要があります。ユーザーの発言だけで判断できない場合は、無理に推測せず
一言確認する（例：「金型に使う部品ですか？それとも装置の組み立てに使うFA部品ですか？」）。

確認すべき軸（わかっている情報は聞き直さない）：

- **何を作る/直す/組み立てるための部品か**（設備・機械、金型、成形品、電気配線など）
- **部品そのものの種類**（ねじ・ベアリング・センサ・フレームなど、具体的な名前）
- **型番がすでにわかっているか**（ミスミ品番、または他社品番・図面）
- **法人利用か個人利用か**（ミスミは基本的にBtoB＝法人向け卸売サイトです。個人でも
  購入自体は可能な場合がありますが、価格表示や見積が法人利用前提の設計になっている
  点は伝えておくとよい）

入口になります。詳細な中分類・小分類の例は `references/category-map.md` を参照。
以下は2026年時点で確認できた主要な大分類と、代表的な探し物の対応表です。

複数の大分類にまたがるケースもあります。判断がつかない場合や最新の分類名を確認したい
場合は、web_searchで `site:jp.misumi-ec.com <探している部品名>` のように検索して
実際のカテゴリページを確認すること。

## ステップ3：検索方法を提案する

カテゴリのドリルダウンだけでなく、ミスミには複数の探し方があるので、状況に応じて
使い分けを提案する。

1. **型番検索**：ミスミ品番、または他社（メーカー）型番がすでにわかっている場合、
   カテゴリを辿らずサイト内検索窓に型番を直接入力するのが最速。
2. **キーワード検索**：部品の一般名称（例：「タイミングベルト」「アルミフレーム」）で
   サイト内検索し、表示されたカテゴリ階層（パンくずリスト）から適切な小分類に絞り込む。
3. **カテゴリドリルダウン**：探している部品の名前がはっきりしない、あるいは
   「装置にどんな部品が必要か比較検討したい」場合は、ステップ2で特定した大分類の
   トップページから中分類・小分類を辿る。
4. **図面・CADデータからの検索**：規格品番がない特殊形状の場合、ミスミには2D図面
   （PDF/DXF）から見積もりを取れるサービスがあります（詳細・対象範囲は変更される
   可能性があるため、利用時は公式サイトで最新の条件を確認するよう案内する）。

## ステップ4：ページ内容を裏取りする（データ抽出手段）

推薦したカテゴリや検索方法が正しいか裏を取りたいとき、統合ブラウザ（Playwright等の
画面操作型ツール）はなるべく使わず、以下の軽量な手段を優先すること。実際に
jp.misumi-ec.com へアクセスして確認した結果（2026年8月時点）は次の通り。

**分かっている制約：**

- **web_fetchやcurl / Invoke-WebRequestによる直接アクセスはほぼ失敗する。**
  トップページ・検索結果ページ・商品詳細ページのいずれも403 Forbiddenで拒否される
  （Bot対策とみられる）。User-Agentを一般的なブラウザに偽装しても結果は変わらない。
  そのため「HTMLを直接取得して中身を読む」という方針は基本的に成立しないと考えて
  よい。ただし対策は変わりうるので、重要な判断の前には一度試してみて損はない。
- **robots.txt (`https://jp.misumi-ec.com/robots.txt`) と、そこに列挙されている
  sitemap XML群 (`https://jp.misumi-ec.com/sitemap/output/*.xml`) は取得できる。**
  ただしsitemapに含まれるのはURL（カテゴリコード・品番コードを含むパス）のみで、
  カテゴリ名などの可読な情報は含まれない。「そのURL・カテゴリコードが実在するか」
  の確認や、URLパターンの把握には使えるが、単独では内容の裏取りにはならない。

**推薦する手順：**

1. **web_search（`site:jp.misumi-ec.com <キーワード>`）を第一候補にする。**
   検索結果のタイトル（多くは「〇〇の検索結果 | MISUMI-VONA【ミスミ】」のように
   末尾にキーワードが入る）・URL・スニペットから、該当カテゴリの実在や名称の
   手がかりが得られる。これが、統合ブラウザなしでミスミのページ内容を間接的に
   確認できる、実質的にほぼ唯一の手段。
2. **確認できたURLパターンをもとに検索用リンクを組み立て、ユーザーに提示する。**
   ミスミのサイト内検索結果ページは
   `https://jp.misumi-ec.com/vona2/result/?Keyword=<URLエンコードしたキーワード>`
   という形式（2026年8月時点で確認済み）。これを直接取得するのではなく、
   「このリンクをブラウザで開いて確認してください」という形でユーザーに渡す。
3. **上記で足りない情報（価格・在庫・詳細スペック表など）は、ユーザー自身に
   該当ページを開いてもらい、テキストのコピー＆ペーストや保存したHTML/PDF/
   スクリーンショットを共有してもらう。** これが最も確実で、統合ブラウザツール
   なしで正確な情報を得る現実的な方法。
4. どうしても自動でページの描画済み内容を取得する必要がある場合のみ、統合
   ブラウザツールが唯一の手段になる旨を伝えた上で、使用してよいかユーザーに
   確認する。

**注意点：**

- robots.txtには `/vona3/`・`/mypage/`・各種クエリパラメータなど、多数の
  クロール除外パスが定義されている。自動アクセスを行う場合はDisallowに
  該当するURLへのアクセスを避けること。
- 上記の可否（403になる／ならない）はミスミ側のBot対策次第で変わりうるため、
  「この手段が使えなかった」という結果を長期間の前提として断定しないこと。

**利用規約との整合性（2026年8月に条文を確認済み）：**

ミスミの
[利用規約](https://jp.misumi-ec.com/contents/terms/use.html)（改定日2025年12月1日）と
[当サイトをご利用いただく上での注意事項](https://jp.misumi-ec.com/contents/terms/website.html)
（改定日2020年3月27日）を実際に確認した。クローリング／スクレイピングを名指しで
禁止する条文はないが、以下の条項が実質的にそれをカバーしている。

- 「当サイトをご利用いただく上での注意事項」：「当コンテンツは、自由に閲覧いただけ
  ますが、**私的使用その他法律によって明示的に認められる範囲を超えて、使用（複製、
  改変、アップロード、掲示、送信、頒布、ライセンス、販売、出版等を含む）することは、
  当社の事前承諾がない限り、いかなる方法、目的においても禁止**」。
- 利用規約第32条（禁止事項）：「当サイトに不正にアクセスし情報を改ざんする行為」
  「本サービスの運営を妨げ、その他本サービスに支障をきたすおそれのある行為」等を禁止。

これを踏まえて、本スキルの利用は次の範囲に留めること。

- チャット上のその場の質問に答えるためにページ内容を一時的に参照・要約する程度は
  私的使用の範囲内と考えられる。**商品情報・カテゴリ情報などを機械的に大量取得・
  保存してデータベース化するような使い方はしないこと**（複製禁止条項に抵触する
  リスクが高いため、そもそもそうした依頼が来た場合は規約上のリスクをユーザーに
  伝える）。
- **トップページや検索結果ページへのアクセスが403で拒否されるのは、サイト側の
  明確な拒否の意思表示である。User-Agentの偽装など、これを技術的に回避しよう
  とすることはしないこと。** 403が返ったらそこで止め、web_searchやユーザーへの
  確認依頼など他の手段に切り替える。
- robots.txtとsitemap XMLは運営者がクローラー向けに公開している技術ファイルで
  あり、Disallow対象外パスへの通常アクセス（都度1回程度のGET）は許容範囲内と
  解釈できる。ただし前述のDisallowパスには絶対にアクセスしないこと。

## ステップ5：回答の型

以下の型を目安に、簡潔にまとめる（すべての項目が毎回必要なわけではない）。

```
（1文：ユーザーが探しているものの要約）

**推薦カテゴリ**：〇〇 ＞ △△ ＞ □□
理由：（なぜこのカテゴリが合うか、1〜2文）

**探し方のおすすめ**：型番検索 / キーワード検索 / カテゴリドリルダウン のいずれか＋理由

※ カテゴリ名・階層は目安です。最新のカテゴリ構成・在庫・価格は
  jp.misumi-ec.com で直接ご確認ください。
```

判断に使った情報のうち、公式サイトで直接確認できたものは「確立した事実」、
過去の検索結果や一般的な業界知識からの類推は「推測」として、必要に応じて
区別して伝える。
